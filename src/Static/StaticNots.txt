RULES (static methode):
   1. static methode belongs to the class not an object.
   2. Static methode can be accessed directly by class name and don't need by object.
   3. Static methode can access only static data. it cannot access non-Static data.
   4. Static methode call only static methods and cannot call a non-static methode.
   5. Static methode cannot refer to this or super keyword.
